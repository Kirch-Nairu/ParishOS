# ParishOS — Greenfield Forge/NEST Benchmark

**Status:** Experimental static frontend showcase. No parish deployment, backend, authentication, production data or official ecclesiastical records.

## Purpose
A desktop/mobile parish-office demo grounded in the supplied *Philippine Catholic Parish Rectory / Convent Operations* research. It illustrates **service desk**, **sacramental record custody**, **certificate issuance**, **wedding case tracking**, **Mass-intention fulfillment**, **scheduling**, **donation separation**, and **administrative workflow** without pretending to implement canonical/legal decisions.

## Boundaries
All displayed people, counts, church identity, schedules and transactions are **fictional sample data**. No real sacramental register, church seal or signing, no real payment, no live certificate, no personal-data storage and no operational parish claim. Public Vercel deployment is demo-only, not a production approval.

## Benchmark scoring (fixed before work)
100 points: source/authority 15; research/domain correctness 20; responsive visual UX 25; working interactions/accessibility 20; independently inspectable QA evidence 10; Vercel/deployment provenance 10. Critical failures: fabricated real-person records, real confession content, claiming official canonical approvals/certificates, unknown source SHA deployment, unauthorized main merge. Forge retrieval/applicability scored independently from overall product output; a single skilled run cannot prove uplift without a matched baseline.
